# Day 1 后端

运行入口为 `app.main:app`，从项目根目录使用 `python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000`。使用项目虚拟环境，不依赖全局安装。项目根目录的启动脚本负责设置运行数据目录。

`TIANQIONG_DATA_DIR` 可指定数据库与模型验证记录目录；未配置时使用项目内 `.runtime`。运行库为 `tianqiong.sqlite3`。数据库连接逐次打开并显式关闭，外键开启，写操作通过事务提交。当前使用 SQLite 默认回滚日志，本机单进程运行，不支持多 worker 协同调度。

## 当前确实实现的能力

- 首次启动创建虚构校园、8 台模拟设备、一个事件、三份演示资料与四项资源；后续启动不会覆盖或重复种子数据。
- 新建演示场景保留历史事件，每条监测记录都属于明确事件；查询设备状态使用该事件内的最新记录。
- 会话、输入、核查运行、证据结果和执行事件持久化到 SQLite。
- `query_sensor_data`、`query_device_status`、`query_event_history` 是真实执行的本地查询函数。
- 固定演示工作流进行规则初评，结果包含证据 ID、理由、不确定项和规则版本。
- SSE 订阅持久化事件，支持 `after` 或 `Last-Event-ID`；断线不取消业务，停止接口会阻止后续工具调度。
- 进程停止或重启后将未完成运行标记为中断，不假装无缝恢复。

## 明确未实现的能力

当前页面内核查并不使用模型规划，也不执行正式预案检索、审批、派发、任务执行或最终报告生成。独立模型探测成功只证明该次模型工具调用可用，不会将 `model_driven_workflow` 能力改为真。`/api/v1/tasks` 返回空列表，因为处置任务还未接入。

风险规则 `demo-risk-v1` 仅是教学演示：同一地点、同一事件内的有效温度记录达到 60°C 且有烟雾告警时返回演示高风险，单项异常为演示中风险；缺少关键证据不能自动判为低风险。60°C 是人为设定的演示阈值，不是消防标准。所有事件、人员角色、设备和监测数据都是模拟内容。

## 验证与接口

项目根目录运行 `python -m pytest`。测试覆盖种子幂等、场景隔离、真实工具记录、SSE 重连、取消、无证据、请求校验、重启中断和模型元数据隔离。具体测试结果以实际运行输出为准。

运行后 `/docs` 提供接口文档。完整前后端契约位于项目的 `docs/implementation-contract.md`。

模型探测元数据只从 `model_probe.json` 中白名单读取：`provider`、`model`、`configured`、`verified`、`status`、`message`。不读取或返回密钥字段。`ZAI_MODEL` 指定模型名称，`ZAI_API_KEY` 只用于判断环境是否配置；后端启动及工作流不会自动发起收费请求。
