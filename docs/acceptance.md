# 验收清单

## Day 1 必须验证

- 前后端真实启动，页面及静态资源可访问。
- 初始场景可查询；重复启动不重复播种；新场景不覆盖旧场景。
- 提交任务后，数据库中产生运行记录和三项真实工具调用。
- SSE 记录可回放，序号不重复，完成后结束连接。
- 页面刷新和任务详情读取同一运行结果。
- 工作台、设备、风险信息来自同一事件，缺失数据不判为正常。
- 模型探针验证独立记录成功或明确错误，不以模拟探针替代真实调用。
- 核心按钮可操作；后续功能明确标识范围，不伪造成功。
- 关键界面在常用桌面尺寸可读，右栏可收起，输入区不被遮挡。

## Day 3–5 增量验收

- 模型规划与实际工具循环；错误参数、超时、取消、重试。
- 未批准和驳回时不能派发；编辑后旧批准失效；重复确认不重复派发。
- 任务变更与报告快照一致，报告确实可打开、复制、下载。
- 成功、证据缺失、模型不可用三条端到端路径。

实际通过项和已知限制记录在 progress.md，清单本身不代表已完成。
