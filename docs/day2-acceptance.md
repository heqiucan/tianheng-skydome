# 天穹 SKYDOME · Day 02 开发与验收记录

记录日期：2026-11-15。场景为浙江交通职业技术学院杭州校区。本文记录已实现功能、实际交互验收和仍需补充的空间资料；模拟能力与真实系统接入分别说明。

## 1. 交付内容与边界

在原有 Vue、TypeScript、Vite、FastAPI、SQLite 技术栈上，实现「全域态势总览」「数字孪生地图」「空天地协同」三个视图，共用 `/api/v1/situation` 返回的数据。没有为视觉效果引入 Three.js、GIS 引擎或其他重型依赖。

地图采用学校项目的规划效果图，加上可交互的建筑区域、设备、风险事件和巡检路线。它是图片交互地图，不是真实三维模型、实时影像或经过测绘验证的数字孪生。学校素材与 DEMO 业务数据有明确标识。

## 4. 已实现功能

- 一级导航「全域态势」下提供总览、地图、协同三个视图，默认总览；保留 Day 1 智能工作台。
- 总览包含设备与风险统计、风险分布、建筑列表、事件列表、任务记录和事件时间轴；数字由同一态势快照派生。
- 独立 `CampusImageMap` 组件共用图片与 SVG 坐标变换，支持归一化热点、选中高亮、定位、缩放、拖动、复位和全屏入口。
- 建筑详情展示来源、用途、有依据的面积、楼层待核实信息、关联设备、事件与最近巡检；未定位建筑仍可查资料，不伪造位置。
- 设备详情显示唯一编号、位置说明、状态、读数、趋势、更新时间、关联设备和事件，以及 Agent 分析入口。
- 独立图层：建筑、温度、烟雾、视频、消防、无人机、机器人、风险事件、巡检路线，共 9 项；开关真实影响覆盖层。
- 三类初始 DEMO 事件：实训基地温度异常、实验空间设备离线、校园区域消防设备异常；事件与地图标记使用同一数据源。
- 无人机支持设备/目标选择、生成草稿航线、确认、沿路线移动、进度、完成结果、历史与重新执行。
- 地图 Agent 创建持久任务 ID，保存建筑、设备、事件、来源视图、图片及原选中对象上下文，在工作台展示结果并可返回地图。
- 地面机器人提供统一后端定义的 DEMO 待命任务、目标、状态与进度；卫星卡片说明模拟覆盖和未接入状态。

全屏入口的浏览器限制与回退实现，以及最后一轮交互回归，见第 7 节，不能仅凭代码存在判定通过。

## 5. 数据一致性与模拟边界

初始数据为 **9 台设备、3 个事件**。TEMP-008、SMOKE-012、CAM-021、FIRE-003、DRONE-001、ROBOT-001 均已配置；保留 Day 1 的原有设备 ID，并通过 `code` 提供展示编号。升级为幂等迁移，不删除已有会话、执行记录和事件观测。实际运行库包含 Day 1 历史及验收产生的记录，因此页面总数可以超过 3 个事件或出现多个巡检任务，不应为凑固定数字清空历史。

Day 1 的设备接口保留“选中事件快照”语义；Day 2 全域态势读取每台设备各指标的最新观测。两者用途不同，历史事件数据不会被最新状态覆盖。地图任务保存生成时的分析与证据摘要，后续读数变化不改写既有任务结果。

| 项目 | 实际能力与限制 |
|---|---|
| 地图 Agent 分析 | 从统一数据库快照生成确定性 DEMO 规则摘要；没有调用真实 LLM，不宣称模型自主规划 |
| 安全报告 | 区域安全摘要，明确不是正式报告、审批或处置指令 |
| 无人机巡检 | 12 秒模拟动画，时长不是物理飞行估计；服务端时间驱动进度并持久保存结果 |
| 刷新与重启 | 已保存任务可恢复；巡检按开始时间恢复进度，不依赖页面自增计数 |
| 机器人 | DEMO 待命任务与 0% 进度，未实现真实机器人控制或自动执行 |
| 卫星遥感 | 模拟状态卡片，未接入真实影像或遥测 |
| 监测与风险 | 全部演示数据；没有真实学校设备控制、视频识别或现场确认 |
